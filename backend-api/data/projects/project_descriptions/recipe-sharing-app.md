# RecipeShare - Social Recipe Platform

A social platform for sharing and discovering recipes. Users can create recipe collections, share cooking tips, and follow other food enthusiasts. Features include ingredient-based search, nutritional information calculation, and meal planning calendars.

Built with the MERN stack featuring image uploads with Cloudinary, recipe rating system, and social features like comments and bookmarks. The responsive design works seamlessly on mobile devices for kitchen use. Includes a measurement converter and cooking timer utilities.
