# TaskFlow - Task Management App

A collaborative task management application designed for small teams. Built with React and TypeScript on the frontend, with a Node.js/Express backend. Features include drag-and-drop task organization (Kanban style), team workspaces, task assignments, due dates, file attachments, and activity feeds.

The app uses Socket.io for real-time collaboration, allowing team members to see updates instantly. Implemented authentication with JWT tokens and data persistence with PostgreSQL. Includes a notification system for task assignments and deadline reminders.
