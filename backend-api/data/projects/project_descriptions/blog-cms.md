# Blog Content Management System

A modern headless CMS built for managing blog content with a Next.js frontend. Features a rich text editor for creating posts, markdown support, image uploading, and SEO optimization tools. Includes draft management, scheduled publishing, and revision history.

The admin dashboard provides content analytics, comment moderation, and multi-author support. Built with Next.js App Router, Prisma ORM, and PostgreSQL. Implemented ISR (Incremental Static Regeneration) for optimal performance and SEO. RSS feed generation and sitemap automation included.
