# DevOps Dashboard

A comprehensive monitoring and observability dashboard built with Next.js and TypeScript, designed to provide real-time visibility into infrastructure and application health. The dashboard aggregates metrics from Prometheus, logs from Elasticsearch, and traces from Jaeger.

Features include custom alerting with multiple notification channels (Slack, PagerDuty, email), incident response runbooks, on-call scheduling, and automated root cause analysis using ML anomaly detection. Implemented real-time data visualization with D3.js and WebSockets for live metric streaming. Reduced mean time to resolution (MTTR) from 45 minutes to 12 minutes through improved observability and alerting.
