# E-Commerce Platform

A full-featured e-commerce platform built with the MERN stack (MongoDB, Express, React, Node.js). The platform includes user authentication, product catalog management, shopping cart functionality, secure checkout with Stripe integration, and an admin dashboard for inventory and order management.

The application features real-time inventory updates, product search and filtering, user reviews and ratings, and order tracking. Implemented responsive design using Tailwind CSS and state management with Redux Toolkit. The backend REST API handles payment processing, email notifications, and generates sales analytics reports.
