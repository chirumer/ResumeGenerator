# ChatterBox - Real-Time Chat Application

A scalable real-time messaging application built with WebSocket technology. Supports one-on-one messaging, group chats, file sharing, and typing indicators. The frontend uses React with Context API for state management, while the backend leverages Node.js with the ws library for WebSocket connections.

Features include message persistence with MongoDB, online/offline status tracking, read receipts, and push notifications. Implemented user authentication with bcrypt password hashing and JWT tokens. The application handles reconnection logic and maintains message order during network interruptions.
