# Weather Dashboard

An interactive weather dashboard that aggregates data from multiple weather APIs. Built with React and featuring a clean, responsive UI with data visualizations using Chart.js. Users can save favorite locations, view 7-day forecasts, and receive severe weather alerts.

The application includes geolocation support, dynamic backgrounds based on weather conditions, and unit conversion (Celsius/Fahrenheit). Implemented efficient caching strategies to minimize API calls and reduce load times. All weather data is fetched client-side with proper error handling and loading states.
