# Fitness Tracking Mobile App

A cross-platform mobile fitness application built with React Native and Expo, featuring workout tracking, nutrition logging, and progress visualization. The app integrates with Apple Health and Google Fit APIs to sync activity data automatically.

Features include custom workout builders, exercise libraries with video demonstrations, calorie counting with barcode scanning, and social challenges. Implemented offline-first architecture with local SQLite storage and background synchronization. Used React Native Reanimated for smooth 60fps animations and Gesture Handler for intuitive swipe interactions. Published to both App Store and Google Play with 50,000+ downloads and 4.5-star rating.
