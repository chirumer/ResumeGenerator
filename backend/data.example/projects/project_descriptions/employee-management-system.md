# Employee Administration System

A comprehensive HR administration system for managing employee records, attendance, and leave requests. Built as a single-page application with React and TypeScript, featuring role-based access control for administrators, managers, and employees.

Key features include employee onboarding workflows, digital document management, attendance tracking with biometric integration, leave balance calculations, and reporting dashboards. The RESTful backend API is built with Express.js and uses PostgreSQL with Prisma ORM. Implemented comprehensive audit logging for all data modifications.
