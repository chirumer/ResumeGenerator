# Recommendation Engine

A machine learning powered recommendation system built with Python, Spark, and TensorFlow. The engine implements collaborative filtering, content-based filtering, and hybrid approaches to provide personalized recommendations for e-commerce platforms.

Features include real-time inference with Redis caching, A/B testing framework for algorithm comparison, and automated retraining pipelines. Implemented matrix factorization with ALS, neural collaborative filtering, and deep learning models for cold-start problem solving. Optimized database queries for feature extraction using PostgreSQL CTEs and window functions. Achieved 35% improvement in click-through rate and 22% increase in conversion rate compared to previous rule-based system.
