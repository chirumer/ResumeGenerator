# ML Pipeline Platform

An end-to-end machine learning pipeline platform built with Python, Airflow, and Kubernetes. The platform automates the entire ML workflow from data ingestion and preprocessing to model training, evaluation, and deployment.

Features include automated data validation, model versioning with MLflow, experiment tracking, and A/B testing capabilities. The platform supports multiple ML frameworks including TensorFlow, PyTorch, and scikit-learn. Implemented distributed training using Ray and model serving with TensorFlow Serving and Seldon Core. Reduced model deployment time from 2 weeks to 2 days while improving model accuracy by 15% through automated hyperparameter tuning.
